# Quy tắc bắt buộc: Cập nhật `docs/` khi làm bất cứ việc gì

Mọi tác vụ, thay đổi mã nguồn, quyết định thiết kế, kết quả thảo luận (brainstorm) hoặc kiểm thử trong workspace này **bắt buộc** phải được cập nhật đồng bộ vào thư mục `docs/` trước khi kết thúc lượt phản hồi.

1. Luôn kiểm tra và cập nhật `docs/changelog.md` sau mỗi hành động.
2. Cập nhật tài liệu chuyên môn tương ứng trong `docs/` (`brainstorm-and-specs.md`, `architecture.md`, `math-curriculum-g3.md`, `README.md`).
